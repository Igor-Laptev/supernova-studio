# Supernova Studio

Сайт агентства маркетинга и брендинга для проектов в сфере девелопмента и недвижимости.

## Возможности

- адаптивная главная страница;
- разделы услуг, проектов и тарифов;
- отдельные страницы кейсов;
- интерактивная форма заявки;
- статическая генерация страниц кейсов.

## Запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:3000`.

## Сборка

```bash
npm run build
npm start
```

## Стек

Next.js, React, TypeScript и CSS.
