# Supernova Studio

Промо-сайт агентства маркетинга и брендинга для проектов в сфере девелопмента и недвижимости.

## О проекте

Supernova показывает полный цикл работы агентства: услуги, проекты, тарифы и подробные страницы кейсов. Интерфейс адаптирован под разные размеры экранов и построен без UI-библиотек.

### Реализовано

- адаптивная главная страница;
- интерактивный аккордеон услуг;
- форма обратной связи с состоянием успешной отправки;
- динамические маршруты кейсов;
- статическая генерация страниц через `generateStaticParams`;
- отдельные SEO-метаданные для каждого кейса;
- типизированная модель контента;
- переиспользуемые UI- и секционные компоненты;
- поддержка клавиатурной навигации и базовые ARIA-атрибуты.

## Стек

- Next.js 16;
- React 19;
- TypeScript;
- CSS;
- ESLint.

## Архитектура

```text
app/
├── cases/                 # данные и динамические страницы кейсов
├── components/
│   ├── cases/             # представление страницы кейса
│   ├── home/              # секции главной страницы
│   └── ui/                # общие элементы интерфейса
├── data/                  # данные главной страницы
├── layout.tsx             # общая разметка и метаданные
└── page.tsx               # композиция главной страницы
```

Контент отделён от компонентов, интерактивные части изолированы как Client Components, а остальные секции остаются серверными.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Проверка

```bash
npm run lint
npm run build
```
